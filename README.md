# 12-Common-Pattern-Programs-in-Java 

A beginner-friendly Java project that demonstrates 12 commonly used pattern-printing programs using loops, conditional statements, and methods.

## 📌 Project Overview

This project contains 12 different pattern programs in a single Java file. Users can choose a pattern from a menu and specify its size to display the desired output.

It is designed for beginners who want to improve their Java programming skills and understand nested loops.

## 🚀 Features

- 12 different pattern programs in one file.
- Menu-driven program using `switch`.
- User input for pattern selection and size.
- Uses Java loops, conditional statements, and methods.
- Easy to understand and modify.
- Suitable for beginners and Java practice.

## 🧩 Patterns Included

1. Solid Square Pattern
2. Right-Angled Triangle Pattern
3. Inverted Right Triangle Pattern
4. Pyramid Pattern
5. Inverted Pyramid Pattern
6. Diamond Pattern
7. Hollow Square Pattern
8. Number Triangle Pattern
9. Floyd's Triangle
10. Alphabet Triangle Pattern
11. 0-1 Triangle Pattern
12. Butterfly Pattern

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone (https://github.com/CodeHub-ui/12-Common-Pattern-Programs-in-Java/)
```

Replace `https://github.com/CodeHub-ui/12-Common-Pattern-Programs-in-Java/)` with your actual GitHub repository URL.

### Step 2: Open the Project Folder

```bash
cd PatternPrograms
```

### Step 3: Compile the Java File

```bash
javac PatternPrograms.java
```

### Step 4: Run the Program

```bash
java PatternPrograms
```

### Step 5: Select a Pattern

Enter a number between 1 and 12, then enter the desired pattern size.
